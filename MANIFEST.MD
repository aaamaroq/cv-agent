
### Project Summary: AI-Powered Interactive Portfolio & CV

#### 🎯 Overview

Build an interactive web portfolio and CV for an **AI Engineer**. The core of the project is a conversational chatbot that answers recruiters' and hiring managers' questions about experience, projects, and technical vision, while also serving as a **real technical proof** of the developer's capabilities.

#### 🛠️ Main Tech Stack

* **Language:** Python (mandatory).
* **Orchestration Framework:** LangChain (the main focus is to master this framework from 0 to 100, using the project itself as a way to learn it).
* **Vector Database:** Local/lightweight for the RAG pipeline (e.g., ChromaDB).
* **Initial Interface:** Streamlit or similar for fast iteration without frontend friction.

#### 🚀 Evolutionary Development Approach (Vehicle Metaphor)

The project will be built organically, where each phase delivers a fully functional product that evolves significantly compared to the previous one:

1. **🛹 Skateboard (Phase 1):** Basic Python script with an ultra-simple interface. An LLM connected via LangChain with the CV pasted directly into the static *System Prompt*.
Next could be a 🚲 Bicycle; this will depend on the changes made, so that the leap between vehicles is smooth. Avoid making huge leaps like going straight from a car to an airplane—that would be ridiculous, but the progression should still reflect the planned roadmap (though this will always be discussed with the user first). This is just a convention for the branches/steps.

#### 📌 Guidelines for the Assistant Agent

* Prioritize clean Python code and AI engineering best practices.
* Focus on leveraging **LangChain's** native features at each milestone and teaching the user.
* Iterate step by step (from the skateboard to the airplane), without overcomplicating the architecture from the start, always keeping an operational, working product.
